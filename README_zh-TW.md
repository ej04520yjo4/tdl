# TDL 繁體中文下載助手

直接雙擊專案根目錄的 `TDL下載助手.exe`。已包含桌面視窗與 tdl 核心，不需要另外安裝 Python、Go 或 Telegram Desktop。

適用 Windows 10／11 64 位元。第一次啟動單檔程式需要解壓縮內含元件，可能稍等數秒。

目前版本為 1.2.0：下載佇列可獨立上下捲動，每個檔案固定顯示自己的進度；正常關閉會保存未完成工作，重開後自動接續；論壇群組可選擇單一話題／子群組下載。保留 1.1.1 的「更新清單」閃退修正。更新後請先關閉舊視窗，再重新開啟 EXE；原有帳號與設定可繼續使用。

## 第一次使用

1. 在「帳號管理」新增一個方便辨識的帳號名稱。
2. 建議選擇 QR Code 登入。在手機 Telegram 的「設定 → 裝置 → 連結桌面裝置」掃描畫面上的 QR Code。
3. 也可選手機號碼登入，使用含國碼的電話，例如 `+886912345678`。驗證碼可能送到 Telegram 已登入的裝置；若帳號啟用兩步驟驗證，再輸入密碼。
4. 到「頻道下載」，選擇帳號並更新頻道清單。可以搜尋名稱，點選要下載的頻道或群組。論壇群組會載入「話題／子群組」清單，請再點選要下載的話題；不會預設下載全部話題。
5. 選擇起日、迄日與媒體類型。預設為影片，也可選照片、音訊與文件。日期按台灣時間（UTC+8），包含起日 00:00:00 至迄日 23:59:59。
6. 先掃描符合條件的媒體，確認數量及下載資料夾，再開始下載。程式會自動切到「下載中心」顯示進度，可取消、重試或開啟下載資料夾。掃描本身不會下載附件；改動頻道或篩選條件後，需重新掃描。
7. 下次開啟會記住帳號登入狀態、設定及未完成工作。使用原下載帳號自動繼續；Telegram 撤銷連線或要求重新驗證時，仍需再次登入。

## 常見操作

- 取得連結：在 Telegram 對包含附件的訊息選擇「複製訊息連結」。頻道首頁與加入群組的邀請連結不是附件連結。
- 按頻道下載：在「頻道下載」選取已有權限的頻道或群組，依日期及類型產生清單。此流程只下載清單中的媒體，整組相簿選項不會擴大篩選範圍。
- 子群組／話題：選擇論壇群組後，先選話題，再選日期及檔案類型。「一般」也是獨立話題。只有明確選取「全部主題」才會掃描整個論壇群組。更換群組、話題或條件後須重新掃描。
- 單則或批次連結：使用「下載中心」貼上 Telegram **訊息連結**。只有頻道名稱或頻道首頁的網址，請改用「頻道下載」。
- 批次下載：一次貼上多行訊息連結；重複連結會去除。
- 私人群組／頻道：使用目前帳號原本就能讀取的訊息連結。
- 相簿：開啟「下載整組相簿」會一併取得同組媒體。
- JSON 清單：選取 Telegram Desktop 或 tdl 匯出的 JSON 清單下載其中附件。
- 相同檔案：預設跳過符合名稱和大小的檔案；檔名包含聊天與訊息 ID，減少不同訊息互相覆蓋。
- 下載佇列：在佇列區域使用滑鼠滾輪或右側捲軸上下查看；新進度不會把你正在查看的位置拉走。多個檔案各有固定的檔名和進度列。
- 中斷處理：正常關閉會暫停並保存，同一筆工作重開後自動接續，略過已完成附件。正在下載而尚未完成的單一檔案可能從頭重抓，不宣稱位元組續傳。
- 手動取消／下載失敗：保留工作，須按「重試」才再次下載，不會在重開時自動啟動。
- 關閉視窗：有進行中工作時，畫面會顯示正在保存進度；請讓程式完成關閉。匯入的 JSON 會保留工作副本，原清單移動或刪除後仍能繼續。
- 代理伺服器：需要時才設定 `socks5://主機:連接埠` 或 `http://主機:連接埠`。

## 帳號與資料

桌面版使用 `%LOCALAPPDATA%\TDLDesktop` 保存自己的資料，與原版命令列的 `%USERPROFILE%\.tdl` 分開。驗證碼與兩步驟驗證密碼只用於當次登入，不保存到設定或下載紀錄。

帳號工作階段使用 Windows DPAPI 加密，正常完成操作後會移除供核心使用的暫存明文資料。加密資料綁定目前 Windows 使用者，直接複製到另一台電腦或另一個 Windows 帳號不能當作登入備份。程式執行中會暫時解密；若遭強制終止或斷電，可能留下暫存資料，下次啟動會嘗試重新封存。下載的附件本身不會加密。

移除帳號只清除此程式保存的本機登入資料，不刪除你的 Telegram 帳號或已下載的檔案。若需要撤銷 Telegram 裝置連線，請在手機 Telegram 的「設定 → 裝置」管理。

## 建置與修改

- `desktop/app.py`：繁體中文原生視窗。
- `desktop/backend.py`：帳號、設定、下載工作與核心執行管理。
- `desktop/channel_page.py`：頻道清單、日期篩選、媒體掃描與下載預覽。
- `pkg/desktopio`：桌面版與 Go 核心之間的輸入、事件與取消協定。
- `desktop/build.ps1`：建置核心、執行測試，再打包單一 EXE。
- `desktop/HANDOVER.md`、`desktop/handovers/`：每次更新的交接清冊、驗證與 GitHub 同步資訊。
- 原本 tdl 命令列仍保留；桌面版以 `TDL_GUI=1` 啟用額外協定。

在專案根目錄，以 PowerShell 執行：

```powershell
.\desktop\build.ps1 -Python '你的 Python 環境\python.exe' -Go '你的 Go\bin\go.exe'
```

Python 需要安裝 `desktop/requirements.txt` 所列套件，Go 版本需滿足專案的 `go.mod`／`go.work`。輸出在 `dist` 並複製至專案根目錄。建置工具不會放進交付的 EXE。

實際 Telegram 登入和下載需要你本人的帳號、網路及可存取的訊息。開發用 `desktop/verify_qr_release.py` 使用臨時資料驗證 EXE 能取得並顯示 QR Code，隨即取消。`desktop/verify_channel_release.py` 使用已記憶帳號的隔離副本，驗證清單、日期／影片篩選及下載一個公開頻道的小型影片；`desktop/verify_channel_ui_release.py` 則實際操作 Windows 原生視窗的「更新清單」按鈕、搜尋與選取，檢查畫面更新的執行緒及正常關閉。測試資料用完即清除，報告不含帳號資料或頻道名稱。這些連線測試必須明確執行，正常啟動不會自動進行。

`desktop/verify_restart_release.py` 使用離線模擬核心，將最終 EXE 分兩次啟動，驗證關閉保存、原帳號與同一筆工作恢復，以及已完成檔案沒有重寫；這項測試不使用真實 Telegram 附件。各項結果與限制見 `desktop/VALIDATION.md`。
