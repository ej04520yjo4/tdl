# 1.4.0 交接清冊

日期：2026-10-22。基底：master `14e4d519f5166a40e0330e260847e3924f00b20c`。

## 需求與操作流程

使用者在搜尋、下載後切換頻道時，無法確認目前選取的頻道，要求檢查並改善整體使用流程。

- 頻道頁明確呈現目前頻道／群組及論壇話題；掃描結果呈現其來源、日期、類型與數量。
- 更換頻道、話題、日期或媒體類型會使舊結果失效，必須重新掃描；搜尋清單不會偷偷選取其他頻道。
- 加入下載後留在頻道頁，顯示加入確認。「換另一個頻道」清除搜尋及選取，保留日期、類型與保存位置；既有佇列繼續處理。
- 「查看下載佇列」直接定位下載進度區；「繼續選頻道」返回原選取狀態。
- 同一份已加入的掃描結果不會因重新搜尋、刷新帳號資訊或操作狀態切換而重新開放加入。

## 維護位置

- `desktop/channel_page.py`：目前來源、掃描快照、條件失效、加入確認及切換頻道操作。
- `desktop/app.py`：加入佇列確認與雙向導覽。
- `desktop/tests/test_channel_workflow_ui.py`：切換與非同步結果回歸測試。
- `desktop/workflow_probe.py`、`desktop/verify_workflow_release.py`：最終 EXE 的隔離離線操作流程與畫面驗證。
- `desktop/build.ps1`、`desktop/package_release.py`：建置與版本綁定收據。

## 相容性與限制

帳號、設定、快取、既有下載與資料夾對應沿用原格式；未搬移或重設使用者資料。論壇群組仍須明確選取話題，只有選擇「全部主題」才會掃描整組。日期仍依台灣時間及訊息進入目前群組的日期篩選。

本次使用隔離測試帳號及離線模擬結果，不使用真實 Telegram 帳號或附件傳輸。離線成功不代表每個頻道的媒體都能從 Telegram 下載。下載接續仍以檔案為單位；Windows EXE 未簽章。
