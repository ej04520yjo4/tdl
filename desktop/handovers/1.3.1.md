# 1.3.1 交接清冊

日期：2026-10-13。基底：1.3.0，`4290b625e7362f2911229f115d5f4cd2486f9f7c`。

## 本次需求

使用者確認直接修正檢閱提出的三個問題：備份失敗保護、副檔名大小寫篩選、還原失敗帳號清理。每次更新提供交接清冊、Windows 單一 EXE 並同步 GitHub。

## 修改與維護位置

1. 備份先寫入目的地同資料夾的暫存檔，完整寫入及關閉成功後才替換舊備份；失敗或提交前取消保留既有備份。維護位置：`app/migrate/backup.go`。
2. 上傳與下載的副檔名包含／排除條件不分大小寫，保留實際檔名。維護位置：`app/up/walk.go`、`app/dl/iter.go`。
3. 背景工作先釋放帳號鎖與使用紀錄，再通知呼叫端完成，讓還原失敗的清理確實完成。維護位置：`desktop/backend.py`。
4. 發行版本來自 `desktop/version.py`；建置流程加入備份的 Go 回歸測試。

## 已知限制

- 作業系統強制終止或斷電可能留下未提交的暫存檔；提交前不會用它覆蓋舊備份。
