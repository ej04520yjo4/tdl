日期：2026-10-13。基底：1.3.1，`c04aa5f16e13d3c15e933434946198866a0aae99`。

## 本次需求

- 下載檔案先依群組／頻道名稱建立資料夾，再存放附件。
- 延續每次更新交付 Windows 單一 EXE、交接清冊與同步 GitHub 的要求。

## 實作與相容性

頻道／群組、論壇話題與下載紀錄共用繁簡搜尋比對；顯示名稱與檔案名稱維持原文。

搜尋使用 Windows 內建 `LCMapStringEx`，並處理 Unicode 正規化、英數大小寫及 UTF-16 字元長度；沒有新增需另外安裝的轉換套件。這是文字繁簡轉換，不是同義詞搜尋。

新下載工作預設依對話名稱分資料夾，適用訊息連結與頻道掃描清單。舊工作缺少此設定時維持原本路徑，重開或重試不會改放位置，也不搬移過去已下載的檔案。

同一帳號與下載根目錄會記住群組 ID 對應的資料夾。群組日後改名仍沿用首次建立的資料夾，避免接續時分散檔案；同名資料夾會加上群組識別後綴，Windows 不允許的字元會整理。對應資料保存在帳號核心儲存區，與既有登入資料一起封存。

## 操作方式

關閉舊視窗後開啟根目錄 `TDL下載助手.exe`（2026-10-17 起已是 1.3.2，見文末交接確認）。例如搜尋「台灣群組」也能找到「台湾群组」，直接貼上 `@username` 也可搜尋。選定 `D:\影片` 下載根目錄後，新工作會寫到 `D:\影片\群組名稱\檔案`；選擇群組中的話題時，仍放在該群組資料夾裡。

## 維護位置

- `desktop/search.py`：繁簡、Unicode 與大小寫搜尋鍵。
- `desktop/channel_page.py`、`desktop/app.py`：搜尋接入、資料夾說明、下載工作建立與舊工作恢復。
- `desktop/backend.py`：保存與恢復 `group_by_chat`，傳入 `--group-by-chat`。
- `app/dl/iter.go`、`app/dl/folders.go`、`app/dl/dl.go`、`pkg/key/key.go`：安全資料夾名稱、永久名稱對應、實際檔案路徑及進度相容。
- `desktop/restart_probe.py`、`desktop/verify_release.py`：最終 EXE 繁簡比對與兩程序接續驗證。

## 已知限制

- 繁簡搜尋使用 Windows 內建字元映射，不提供同義詞、拼音或語意搜尋；非 Windows 開發環境僅退回 Unicode／大小寫比對。
- 群組資料夾名稱在同一帳號與下載根目錄中保持穩定；手動移動／改名資料夾，或使用不同帳號，無法保證沿用原對應。
- 舊檔案不自動搬移；未完成的單一附件仍可能重新下載，接續以檔案為單位。
- 上游完整 Go suite 的既有 Windows `app/update/TestBinaryName` 差異不在本次範圍；不宣稱全套 Go suite 通過。
- Windows EXE 未簽章。
