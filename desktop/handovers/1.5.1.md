# 1.5.1 交接清冊

日期：2026-10-25。基底：1.5.0 `2fa8c1e`。功能分支：`codex/download-destination`。

## 需求與操作

使用者希望下載時可以選擇目的位置。本版提供電腦資料夾選擇，不涉及向 Telegram 群組傳送訊息。

1. 在頻道下載完成掃描後按「② 加入下載」，或於下載中心按「開始下載」。
2. 選擇這次的儲存位置；選擇器從上次位置開始。檔案仍放入該位置下的群組／頻道名稱子資料夾。
3. 取消選擇不會新增工作，頻道掃描結果仍保留。
4. 在「設定與說明」取消勾選「每次新增下載時選擇儲存位置」，可直接沿用上次位置。

## 修改與相容性

- `desktop/app.py`：連結下載選擇器、偏好開關、三頁儲存位置同步；選擇後僅排隊保存下載路徑，避免其他設定將新位置蓋回舊值。
- `desktop/channel_page.py`：頻道下載選擇器與取消提示、手動輸入路徑完成後保存。選擇視窗返回後重新檢查掃描來源，避免期間切換帳號或頻道時送出舊結果。
- `desktop/backend.py`：新增 `ask_download_folder` 布林偏好，預設開啟；舊設定缺欄位時自動沿用預設。
- 現有工作、重試及重開接續保留工作內原路徑，不搬移附件、不彈出選擇器。更換位置不會使原有掃描失效。
- `desktop/package_release.py`：沿用現有 PR #4 提交 `d5d7a9d` 的 LF 校驗檔修正及測試，讓 Windows 產物可由其他系統校驗；未修改或合併該 PR。
- `desktop/tests/test_download_destination.py`、`test_channel_destination_race.py`：偏好相容、持久化、跨頁同步、取消與來源變動的回歸測試。
- `desktop/workflow_probe.py`：最終 EXE 的離線資料夾選擇、重開記憶及舊工作路徑驗證。僅在 fixture 內替換原生選擇器的回傳值。

## 已知限制

- 本版不使用真實 Telegram 帳號測試；離線 fixture 不代表實際服務下載驗證。
- 選擇器可以建立及選取資料夾；磁碟斷線、沒有寫入權限等仍由下載工作顯示錯誤。
- 原有按群組建立子資料夾的行為保留。不同話題仍放在所屬群組資料夾。
- 接續以附件為單位；未完成的單一附件可能重新下載。Windows EXE 未簽章。
