1. **Go 單元測試**：備份使用本機假儲存資料與故障注入；副檔名測試不連線 Telegram。
2. **Python 桌面測試**：模擬核心與隔離帳號資料，不存取使用者登入資料。包含還原清理的時序測試。
3. **真實核心、不連線**：確認桌面參數可解析，並以隔離儲存完成備份及還原來回。
4. **最終 EXE、離線**：複製至獨立位置、移除 Python／Go 的 PATH，確認內含核心、畫面繪製及原生 Windows 視窗啟閉；另以兩個 EXE 程序與模擬核心驗證關閉後接續。

- 備份仍為原版相容的未加密 `.tdl` 格式。
- 上傳及轉傳的 Telegram 真實傳送行為未在本版驗證。
- 下載為檔案層級接續，未完成的單一附件可能重新下載。
- 原始專案完整 Go suite 有既有 Windows `app/update/TestBinaryName` 差異；本次執行相關套件，不宣稱全套 Go suite 通過。
- EXE 為未簽章的 Windows x64 GUI 程式。
